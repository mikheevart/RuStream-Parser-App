# RuStream-Parser-App 📺📊

Современное веб-приложение на фреймворке **Streamlit**, предназначенное для парсинга, анализа и извлечения данных из видеоплатформы **Rutube**. Приложение предоставляет удобный графический интерфейс (UI) вместо скучной командной строки, позволяя пользователям гибко собирать контент в пару кликов.

## ✨ Ключевые особенности

- **Удобный Web UI:** Интуитивный интерактивный интерфейс, созданный на **Streamlit** (никакого сложного фронтенда — чистый Python).
- **Гибкий парсинг:** Сбор метаданных видео (названия, просмотры, лайки, авторы, даты публикации) или ссылок по ключевым словам/каналам.
- **Экспорт данных:** Возможность скачать результаты парсинга в удобном формате (CSV / Excel) прямо из интерфейса.
- **Визуализация (опционально):** Интерактивные графики и аналитика по собранным данным (например, топ-видео по просмотрам).

## 🛠 Стек технологий

- **Интерфейс:** Streamlit
- **Парсинг:** Python 3, BeautifulSoup4 / Selenium / Requests (выберите нужное)
- **Анализ данных:** Pandas, NumPy
- **Визуализация:** Plotly / Matplotlib (если используется)

## 🚀 Как запустить проект локально

### 1. Клонируйте репозиторий
```bash
git clone https://github.com
cd RuStream-Parser-App
```

### 2. Настройте виртуальное окружение
```bash
# Для Windows
python -m venv venv
venv\Scripts\activate

# Для macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Запустите Streamlit-приложение
```bash
streamlit run app.py
```
После запуска приложение автоматически откроется в вашем браузере по адресу `http://localhost:8501`.

## 📂 Структура проекта
- `app.py` — основной файл инициализации интерфейса Streamlit.
- `parser/` — логика парсера (скрипты для запросов к Rutube и обработки HTML/API).
- `requirements.txt` — список зависимостей проекта.
